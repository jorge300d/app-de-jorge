# JorgeTap

Tienda de JorgeTap: tarjetas NFC de reseñas en Google (S/ 59), páginas web y publicidad en Instagram, Facebook y TikTok para negocios. Los pedidos llegan por WhatsApp.

Se publica en Netlify desde la rama `main`. Para cambiar precios, marca o WhatsApp, edita el bloque `CONFIG` al inicio del script en `index.html`.
